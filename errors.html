Exercise 1: Six Broken Snippets

How to use this file
  1. Open this page in Chrome, then open DevTools (F12) and go to the Console tab.
  2. You will see 6 red errors, one for each snippet below. Each snippet is in its own <script>, so one error doesn't stop the others.
  3. Do not change any code yet. For each error, write in errors.md:
    • the error type (for example, TypeError)
    • what it means in your own words
    • the fix (the corrected line of code)
  4. Click the file and line link on the right of each error (for example errors.html:85) to jump to the exact line in the Sources panel.
